# CompanyProfile_JBI - Jaya Bersama Interior

Modern & Responsive Company Profile Web Application for Jaya Bersama Interior (JBI).

## Features
- **Company Header & Sub-Header**: Interactive scroll-driven logo morphing animation.
- **Vertical Showcase Gallery**: 3-column vertical curtain reveal slider (slide up/down animation).
- **Company Profile Card**: Sleek architectural blueprint background with CTAs.

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS
- Lucide React Icons
